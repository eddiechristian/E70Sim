### TWIHS0–TWIHS2 — Two-wire Interface (I2C controller)
*   **Base Addresses:** `0x4001_8000` (TWIHS0), `0x4001_C000` (TWIHS1), `0x4006_0000` (TWIHS2). IRQs 19, 20 and 41.
*   **Why It's There:** I2C is how the chip talks to sensors and small memory chips: two wires shared by one controller and several devices, each with a 7-bit address. On the SAM E70 Xplained Ultra, TWIHS0 (pins PA3 and PA4) goes to the EXT1 and EXT2 headers.
*   **The Problem:** A driver starts a transfer and waits for a status bit (a byte arrived, the transmitter is free, the transfer is complete). With nothing there, it waits forever, or reads zeros as if they were sensor data.
*   **Logic:** Host mode only. Each controller has its own list of attached devices (`I2cDevice`, in `src/i2c.rs`). The device address and direction are in `TWIHS_MMR` (`+0x04`); `MSEN` in `TWIHS_CR` (`+0x00`) switches host mode on. **Writing:** each byte put in `TWIHS_THR` (`+0x34`) is passed to the device, the first one starting the transfer; `STOP` in `TWIHS_CR` ends it. **Reading:** `START` begins it; each byte appears in `TWIHS_RHR` (`+0x30`) with `RXRDY` set in `TWIHS_SR` (`+0x20`), and reading it lets the next one in. After `STOP` is written the controller takes exactly one more byte, so firmware writes it while the next-to-last byte is waiting, or together with `START` for a single byte. **Internal address:** if `TWIHS_MMR` asks for 1 to 3 bytes, the controller first sends them from `TWIHS_IADR` (`+0x0C`), most significant first; for a sensor this is the register number. **No answer:** if no device has the address, or a device refuses a byte, `NACK` is set and the transfer ends. `TWIHS_IER` / `TWIHS_IDR` / `TWIHS_IMR` (`+0x24` to `+0x2C`) choose which status bits ask for the interrupt.
*   **Not Modelled:** Transfers take no emulated time (`TWIHS_CWGR`, the bus speed, is stored only). Client mode, high-speed mode, SMBus, the FIFO, 10-bit addresses, and faults on the bus itself.
*   **Sources:** Register layout from the SVD; behaviour from chapter 43 of the SAM E70 datasheet in `reference/same70/`.
