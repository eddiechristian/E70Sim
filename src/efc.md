### EFC — Embedded Flash Controller
*   **Base Address:** `0x400E_0C00`
*   **Why It's There:** Controls the on-chip flash: how many wait states a read takes, and the erase / program / lock commands used to rewrite flash contents.
*   **The Problem:** Flash is too slow to be read in one cycle at full clock speed. Before startup code switches to the fast PLL clock it writes a wait-state count (`FWS`, bits 11–8) to the Mode Register (`EEFC_FMR`, offset `+0x00`), and some code reads it back. Code that issues a flash command then loops on the Status Register (`EEFC_FSR`, offset `+0x08`) until `FRDY` (bit 0) is set. If `FRDY` stays zero, execution hangs.
*   **Stub Logic:** Reads of `EEFC_FSR` (`+0x08`) always report `FRDY` set. `EEFC_FMR` is store-and-readback. Writes to the Command Register (`EEFC_FCR`, offset `+0x04`) are logged but no command is carried out; a write without the `0x5A` key in bits 31–24 sets `FCMDE` (bit 1) in `EEFC_FSR` until the status is read. The Result Register (`EEFC_FRR`, offset `+0x0C`) reads 0. The Write Protection Mode Register (`EEFC_WPMR`, offset `+0xE4`) accepts `WPEN` (bit 0) only with key `0x454643` in bits 31–8, and while set it blocks writes to `EEFC_FMR`.
